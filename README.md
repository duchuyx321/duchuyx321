### 📂 Dự án nổi bật

* **🤖 CvProAi (Website)**
    * *Mô tả:* Hệ thống hỗ trợ tạo CV tích hợp trí tuệ nhân tạo để phân tích mức độ phù hợp giữa CV và JD, phát hiện khoảng cách kỹ năng và gợi ý cải thiện. Dự án tích hợp cổng thanh toán tự động (SePay) và cơ chế phân quyền tài khoản (RBAC).
    * *Công nghệ:* NestJS, TypeScript, PostgreSQL, JWT, ReactJS, AI API, SePay.
    * *Mã nguồn:* [Backend](https://github.com/duchuyx321/CvProAi-Backend) | [Frontend](https://github.com/duchuyx321/CvProAi-fontend)

* **🛒 SrcPlace**
    * *Mô tả:* Nền tảng thương mại điện tử phục vụ việc mua bán mã nguồn (source code), hỗ trợ trao đổi tin nhắn thời gian thực giữa người dùng. Tối ưu tốc độ phản hồi bằng Redis Caching.
    * *Công nghệ:* ReactJS, Node.js, Express.js, TypeScript, MongoDB, Socket.IO, Redis.
    * *Mã nguồn:* [Backend](https://github.com/duchuyx321/SrcPlace-backend) | [Frontend](https://github.com/duchuyx321/SrcPlace-fontend)

* **📝 Learn English**
    * *Mô tả:* Ứng dụng hỗ trợ học tiếng Anh qua hệ thống thẻ ghi nhớ (flashcards), quản lý khóa học và theo dõi tiến độ học tập.
    * *Công nghệ:* ReactJS, Node.js, Express.js, MongoDB, RESTful API.
    * *Mã nguồn:* [Source Code](https://github.com/duchuyx321/LearnEnglish)
